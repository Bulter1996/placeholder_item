# Market Assembling Item

适用于 Factorio 2.1。
生成许多占位物品，用来扩展关联箱的id数量有限

启动设置“区别元素物品列表”接受物品内部 name 的 JSON 数组，例如
`["iron-gear-wheel","copper-plate"]`。每个元素都会生成 7 个继承源物品属性的等级，
例如 `b-market-iron-gear-wheel-1` 至 `b-market-iron-gear-wheel-7`。七级依次使用
`b_market_1.png` 至 `b_market_7.png` 作为底图，并在右上角叠加经过赤、橙、黄、
绿、青、蓝、紫浅色染色的区别元素。

每个区别元素单独占据“超市物品”Tab 中的一个子分组。第 1 级消耗 1 个区别元素，
之后每一级消耗 1 个前一级物品，全部制作时间均为 1 秒。

找不到配置的物品 name、遇到非字符串、重复项或无图标物品时，模组会在日志中记录
原因并跳过该项，不会因此中断加载。

全部生成物品都位于独立的“超市物品”制作 Tab 中。

## 七级管道泵

模组固定新增 `b-tiered-pump-1` 至 `b-tiered-pump-7` 七种管道泵，与启动设置生成的
占位物品相互独立。七级依次使用赤、橙、黄、绿、青、蓝、紫遮罩，并与原版泵位于
同一制作分组；物品图标、地面物品、泵主体和流体车连接机构保持相同等级颜色。

赤色一级由 2 个原版泵合成，之后每一级由 2 个前一级泵合成。每提升一级，流量、
工作功率和待机功耗均翻倍；生命值则每级增加一份原版生命值，从一级的 2 倍递增
至七级的 8 倍。紫色七级的流量和耗电最终达到原版的 128 倍。所有配方随原版
“流体处理”科技一同解锁。

原版泵至紫色泵组成连续的 `next_upgrade` 路线，可由升级规划器和建筑机器人执行
升级或降级替换，也可以手持高级泵直接覆盖低级泵；方向、线路和控制配置由原生
快速替换机制继承。拆除后始终返还当前等级的泵。模组不提供把高级泵无损拆成两个
低级泵的配方。启用原版 Recycler 时，游戏会根据逐级合成配方自动生成默认的有损
回收配方。

## 安装

将发布 ZIP 放入 Factorio 的 `mods` 目录，或直接将本目录作为
`placeholder-item` 放入 `mods` 目录。

## 测试命令

进入地图后可在控制台输入：

```text
/c game.player.insert{name="b-market-iron-gear-wheel-1", count=1}
```
